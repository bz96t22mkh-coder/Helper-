# Module 23 — Channel Editing Style Guide

> **In short:** This last module is a template, not a lesson. Copy it into its own file and update it as you learn what the channel's audience actually responds to.

This module is different from the rest — it's a **living document template**. Copy the template below into its own file (for example, `00-ASSETS-LIBRARY/channel-style-guide.md`) and update it as the channel grows. Check back on it roughly every 5–10 videos.

## Why this exists

Modules 8 and 9 were clear about this: study creators like CoryxKenshin for the *ideas* behind high-energy, personality-driven editing — never to copy them frame-for-frame. This document is where that understanding turns into something that's actually **ours** — specific choices that make this channel's videos recognizable, even with the sound off.

The goal, in plain words: **funny + energetic + clean + personality-driven + unpredictable + entertaining.** This document is where "how we specifically do that" gets written down, instead of re-decided from scratch every video.

## How to actually use it

- **After every video, or every few videos**, spend five minutes updating this — based on what actually happened. Comments, watch-time if you have it, and your own honest sense of what landed.
- **Before starting a new video**, skim it. Not as a strict rulebook (Module 8's "unexpected edits," and this course's goal of being "unpredictable," both argue against rigid rules) — just as a reminder of what you've already learned about this specific channel.
- **Treat contradictions as useful information, not mistakes.** If something in "things that are specifically us" stops landing a few videos later, update the document. Don't force consistency with an old version of the style that's moved on.

## You're done — here's what you've built

- A working software setup.

That's the whole goal: take raw footage, and on your own, make something a viewer watches and thinks, *"this is so entertaining, I want to keep watching."*
