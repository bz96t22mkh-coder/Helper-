# Module 4 — Where to Get Assets

For every category below: check the license on the source's actual current license page before using anything for a monetized video — the specifics here are accurate as of when this was written, but licensing terms and free/paid tiers change. This is the practical companion to Module 3's "how to check" process.

**Legend:** 🆓 Free · 💰 Paid · ✅ Commercial/monetized YouTube use allowed · ⚠️ Conditions apply · 📝 Attribution required

## 😂 Memes / Reaction Images

This is the riskiest category — **read this carefully.** Most viral meme templates are built on a photo, screenshot, or frame that is itself copyrighted (a photographer's picture, a movie/show frame, a video game screenshot). The meme's popularity or "everyone uses it" status has **no bearing** on whether it's legally clear — several real lawsuits have come from exactly this (photographers suing over famous meme-template photos being used commercially). Treat "meme from a random image search" as unverified, not safe.

Safer approaches, in order of preference:
1. **Make your own reaction assets from the creator's own footage** — screenshotting the creator's own facecam reaction, a frame from the creator's own gameplay, etc. You already own the rights to this because it's the channel's own content. This is genuinely the safest "meme" source for a channel like this, and Module 5 covers building a personal reaction-image library this way.
2. **Meme generator platforms with their own stated commercial terms** (e.g., Imgflip and similar) — some explicitly address commercial use of generated images in their terms. Read the current terms page before relying on this, since it can differ from "just downloading a meme image" off social media.
3. **Purpose-built creator libraries** (Envato Elements, Storyblocks-style overlay/meme packs, Artlist's template library) that explicitly license meme-style graphic assets for commercial video use.
4. **Avoid:** downloading a meme image straight from Google Images, Pinterest, Reddit, or a random Twitter/X post and dropping it into a monetized video. There's no license attached, no way to verify the underlying image's rights holder, and — per Module 3 — "I found it on Google" or "it's everywhere online" is not a license.

## Building your own reusable asset library

Once you've verified a source and downloaded assets from it, don't re-download or re-verify it every time you need it — pull it into your shared `00-ASSETS-LIBRARY/` (Module 1) once, organized by category (Module 5 gives the exact structure), and keep a simple running note of **where each batch came from and what license it's under**, e.g. a `sources.txt` file in each library subfolder:

```
Music/Comedy-Upbeat/sources.txt
---
bouncy-ukulele-loop.mp3 — Epidemic Sound, subscription license, no attribution needed
retro-8bit-win.wav — Pixabay, no attribution needed
```

This turns "is this safe to use" from a per-video question into a one-time check per asset, done properly and recorded once.
