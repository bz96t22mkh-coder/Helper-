# Module 5 — Building the Meme & Sound-Effect Library

> **In short:** Build one organized folder of pre-checked memes, sounds, and music, sorted by feeling (shock, victory, fail, etc). Then you never have to hunt for the right asset mid-edit.

A fast comedic editor isn't fast because they type or click quickly. They're fast because they never have to **search** for the right asset. This module builds that system.

## Sort by feeling first, then by file type

Here's the key idea: when you're editing, you don't think "I need a GIF." You think "this moment needs **shock**." So sort by feeling first. Build these folders inside `00-ASSETS-LIBRARY/Memes-Images/`, `Memes-GIFs/`, and `SFX/`:

- Funny reactions
- Shock
- Confusion
- Disbelief
- Fail
- Victory
- Awkward
- Suspense
- Dramatic
- Chaos
- Gaming (level-up, damage, achievement, death sounds)
- Celebrations
- Rage
- Surprise

What this looks like in practice:

```

├── Memes-Images/
│   ├── Shock/
│   ├── Confusion/

│   └── ... (one folder per feeling above)
├── Memes-GIFs/

│   ├── Chaos/
│   └── ...
├── SFX/
│   ├── Shock/            ← record scratch, glass break, gasp
│   ├── Fail/              ← sad trombone, deflate, error buzz
│   ├── Victory/           ← fanfare, ding, chime
│   ├── Suspense/          ← rising tension sound, heartbeat
│   ├── Gaming/             ← general game sounds
│   └── ...
├── Music/
│   ├── Comedy-Upbeat/
│   ├── Suspense-Tension/
│   ├── Sad-Sentimental/
│   ├── Hype-Energetic/

    └── Clean-Readable/    ← for normal captions
```

Keep the `sources.txt` file from Module 4 inside each folder, so you always know where an asset came from and if it's safe to use.

## How to fill it up

For each folder, aim for **quality over quantity**. 5–8 great, different options per folder beats 40 near-copies you'll never actually scroll through in time. Build it slowly:

1. Grab a first batch from the Module 4 sources — search "record scratch" on Pixabay or Epidemic Sound, grab 3–4 different ones, put them in `SFX/Shock/`.
2. When you watch other creators for inspiration (not to copy directly), notice the *moments* that made you laugh. Then go find or make your own version for that same feeling.
3. Before saving any new asset into the shared library, run it through the Module 3 check first. The library should only ever hold pre-checked assets — that's what makes it fast to use later.
4. Clean it out sometimes. If you never reach for something, it's just clutter making your real favorites harder to find.

## Make your own reaction library — the safest option

As covered in Module 4, the creator's own facecam reactions are the safest reaction assets you can use. They're already the channel's own content. Every time you're editing and the creator has a great, reusable expression — a shocked face, a flat stare, a big laugh — clip a short 1–2 second loop or freeze-frame. Save it into the matching `Memes-GIFs/` or `Memes-Images/` folder. Over time, this becomes the channel's own signature reaction bank — something no other channel has.

## Don't turn the video into a pile of memes

A well-stocked library is a tool. It becomes a problem the moment you use every available meme just because it's there. That makes a video feel messy instead of funny.

Follow these rules:

- **Every meme or sound must respond to something specific** that just happened. Never place one just to fill a quiet moment.
- **One strong choice beats three weak ones stacked together.** If you're about to add a meme *and* a zoom *and* a sound *and* a freeze-frame to the same three seconds, ask if the moment is really big enough for all four.
- **Change it up.** If the same three memes show up in every video, they stop feeling like jokes and start feeling like a habit. A good, sorted library (this whole module) makes variety easy.
- **Silence or a plain cut can be the right choice.** Having the library doesn't mean you have to use it every time. Module 7 covers exactly when doing *nothing* is the stronger edit.
