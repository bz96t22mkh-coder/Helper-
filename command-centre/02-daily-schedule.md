## 2. The core rule (do not violate this)

**Stable phase → this schedule stays exactly as written, every weekday, for weeks/months.** Only the *content* inside each block changes day to day (which phase/section of Trading, which module of Outsourcing, which module of the YouTube course). The schedule itself only changes when a Phase's "Complete Phase" button is clicked (see `01-notion-architecture.md` §9) and the new phase's real allocation, as defined by that course, genuinely differs — for Trading this is now driven by the actual 22-phase ladder in `03-goals-and-phases.md`, not a guess.

## 5. WHAT TRIGGERS A SCHEDULE CHANGE (and what doesn't)

| Does NOT change the schedule | DOES change the schedule |
|---|---|
| A new day starting | A Phase's "Complete Phase" button is clicked |
| Finishing one lesson/section/module | A course is fully completed (e.g. Trading Phase 12 → Phase 13 shifts from pure lessons to bar-replay/backtesting practice) |
| A slightly slow or fast day | A pillar moves from learning → execution (e.g. Outsourcing: course → first outreach) |
| Being 15–20 min over/under on a block | A major milestone/goal is confirmed reached |
| Normal daily variation in energy | AI Agency or Crypto unlocks (see `03-goals-and-phases.md`) |
| | Workload materially changes (e.g. first paying customer changes Outsourcing from 2h learning to 2h+ fulfillment work) |
